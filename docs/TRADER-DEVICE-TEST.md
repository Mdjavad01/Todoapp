# چک‌لیست تست دستگاه — فاز تریدر (چک‌لیست تریدر)

> برای هر ردیف فقط یکی از «انجام شد» یا «ناموفق» را پر کنید و مشکل را در «توضیح» بنویسید.
> پیش‌نیاز: APK جدید ساخته‌شده از کامیتِ فاز تریدر (versionCode ۱۰ / نسخه ۱.۰.۹) + سرور با SQL اجراشده‌ی `upgrade-v1.9.1.sql` (ترتیب: `docs/TRADER-DEPLOY.md`).
> زمان کل: حدود ۳۰–۴۵ دقیقه. گوشی آزمایشی: اندروید ۱۳ یا بالاتر پیشنهاد می‌شود.

## نکته‌های شناخته‌شده (باگ نیست)

- یادآور فقط در **اپ اندروید** واقعی است — وب/PWA زنگ نمی‌زند (سناریوهای ۲–۴ را روی APK تست کن).
- نمونه‌ی تازه‌ی آیتم تکرارشونده فقط **بعد از تیک** ساخته می‌شود (محدودیت صادقانه‌ی موتور تکرار فعلی).
- اگر نام یکی از ۵ لیست تریدر را تغییر دهی، بنر قوانین عمداً مخفی می‌شود و فعال‌سازی مجدد ممکن است لیست تکراری بسازد (بدهی ثبت‌شده در ROADMAP — تست نکنید، فقط بدانید).
- برای MIUI/سامسونگ: «اعلان‌ها» و «آلارم دقیق» باید برای کارام مجاز باشند (راهنمای داخل اپ: تنظیمات ← اطمینان از یادآور).
