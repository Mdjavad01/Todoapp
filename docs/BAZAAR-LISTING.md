## ۱) کلید امضا (Keystore) — یکبار برای همیشه ✅ **انجام شد — دیگر نیازی به اجرای این بخش نیست**

> کلید ساخته شد (alias `karam`، اعتبار ۱۰۰۰۰ روز، فایل ۲۲۰۱ بایت) و ۴ Secret با API ثبت شد.
> نسخه‌ی پشتیبان: از داشبورد فرماندهی دانلودش کنید + دو کپی در جای امن (نه گیت!). رمز: در پیام امن.

<details><summary>روش دستی (بایگانی — برای ساخت کلید جدید)</summary>

روی سیستم خودتان (Java نصب باشد؛ در ویندوز با `keytool` همراه JDK):

```bash
keytool -genkeypair -v \
  -keystore karam-release.jks \
  -alias karam \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storetype JKS
```

- به دو سؤال رمز، **یک رمز واحد** بدهید (store password = key password — ساده‌تر).
- نام سازمان را چیزی معتبر بنویسید (مثلاً Hojre24) — در بازار نمایش داده نمی‌شود ولی در امضای اپ می‌ماند.

⚠️ **این فایل (`karam-release.jks`) و رمزش را گم نکنید** — بدون آن هیچ‌وقت نمی‌توانید همان اپ را به‌روزرسانی کنید. دو نسخه پشتیبان در جای امن (نه گیت!).

### ثبت در GitHub Secrets (نام‌ها دقیقاً همین‌ها):

| Secret | مقدار |
| --- | --- |
| `ANDROID_KEYSTORE_B64` | خروجی دستور زیر (کل فایل base64) |
| `ANDROID_KEYSTORE_PASSWORD` | رمز store |
| `ANDROID_KEY_ALIAS` | `karam` |
| `ANDROID_KEY_PASSWORD` | رمز key |

ساخت base64:

```bash
base64 karam-release.jks > karam-release.b64   # ویندوز: certutil -encode karam-release.jks karam-release.b64
```

مقصدها: GitHub ← مخزن Todoapp ← Settings ← Secrets and variables ← Actions ← New repository secret.

## ۲) بیلد APK در ابر (GitHub Actions) ✅ **پوش و Secrets انجام شد — بیلد خودکار فعال شد**

1. ~~ریپو باید به GitHub پوش شود~~ — ✅ انجام شد: `5366927..2cadcf2 main → main` (۲۸ کامیت؛ با پوش، ورک‌فلو خودش فعال شد — نیازی به Run دستی نبود).
2. (در آینده برای انتشار بعدی) تب **Actions** ← «بیلد اندروید کارام» ← **Run workflow** ← Run.
3. بعد از بیلد، در همان اجرا پایین صفحه، آرتیفکت‌ها (بیلد دوگانه — هر دو امضاشده با همان کلید و همان versionCode):
   - `karam-latest-apk` ← فایل `karam-latest.apk` ← **حالت پیش‌فرض (پرداخت روشن) — این برای سایت و به‌روزرسانی کاربران**
   - `karam-bazaar-apk` ← فایل `karam-bazaar.apk` ← **نسخه‌ی بازار (BUILD_MODE=bazaar — کل UI پرداخت از باندل حذف شده) — فقط این فایل برای آپلود در کافه‌بازار**
   - `karam-debug-apk` ← فقط برای تست موبایل خودتان

> ⚠️ **قاعده‌ی مهم:** هرگز `karam-latest.apk` را در پنل بازار آپلود نکنید — برای بازار همیشه **`karam-bazaar.apk`**. کلید `app_update_url` در پنل کارام هم فقط به `karam-latest.apk` اشاره می‌کند (کاربران نسخه‌ی مستقیم از سایت به‌روز می‌شوند؛ کاربران بازار از خودِ بازار).
4. ~~اگر Secret امضا ثبت نشده باشد~~ — ✅ هر ۴ Secret (`ANDROID_KEYSTORE_B64/​PASSWORD/​ALIAS=karam/​PASSWORD`) ثبت شده؛ این اجرا Release امضاشده می‌سازد.

## ۳) دانلود مستقیم APK از سایت (همین امروز، حتی قبل از بازار)

1. آرتیفکت `karam-latest-apk` را دانلود کنید (از قبل با نام **`karam-latest.apk`** بسته‌بندی شده — نیازی به تغییر نام نیست).
2. File Manager هاست ← `public_html` ← آپلود.
3. تست: `https://app.hojre24shop.ir/karam-latest.apk` باید دانلود شود.
4. اعلام نسخه جدید داخل اپ: پنل ← تنظیمات ← «به‌روزرسانی اپ» ←
   - `app_latest_version` = `1.0.0`
   - `app_update_url` = `https://app.hojre24shop.ir/karam-latest.apk`
   - (`app_update_notes` اختیاری — متن کوتاه تغییرات)
   ← از این بعد کاربران نسخه‌های قدیمی، کارت «نسخه‌ی جدید منتشر شده» را در تنظیمات می‌بینند.
5. هر انتشار بعدی: `versionCode` را +۱ کنید، `versionName` را بالا ببرید، همین فایل را جایگزین کنید و `app_latest_version` را در پنل به‌روز کنید. اگر قرار است نسخه‌ی جدید در بازار هم برود، **هر دو** APK (`karam-latest.apk` برای سایت + `karam-bazaar.apk` برای بازار) را از همان اجرای Actions دانلود و به‌ترتیب جایگزین/آپلود کنید — versionCode هر دو یکی است.

> 🔑 کلید `app_update_url` فقط و فقط به نسخه‌ی پیش‌فرض اشاره می‌کند: `https://app.hojre24shop.ir/karam-latest.apk` — هرگز آدرس نسخه‌ی بازاری را در آن نگذارید.
