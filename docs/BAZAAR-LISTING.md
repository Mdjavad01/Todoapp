# انتشار کافه‌بازار + APK مستقیم — بسته‌ی اجرایی کارام (گام ۱۸)

> همه‌چیز برای انتشار در کافه‌بازار و دانلود مستقیم APK از سایت — متن‌ها آماده‌ی کپی‌پیست‌اند.
> وضعیت کد: ورک‌فلو بیلد ابری (`.github/workflows/android-build.yml`)، پروژه‌ی Capacitor و بیلد Gradle با پشتیبانی امضا — همه از قبل آماده‌اند.

## ۱) کلید امضا (Keystore) — یکبار برای همیشه

روی سیستم خودتان (Java نصب باشد؛ در ویندوز با `keytool` همراه JDK):

```bash
keytool -genkeypair -v \
  -keystore karam-release.jks \
  -alias karam \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storetype JKS
```

- به دو سؤال رمز، **یک رمز واحد** بدهید (store password = key password — ساده‌تر).
- نام سازمان را چیزی معتبر بنویسید (مثلاً Hojre24) — در بازار نمایش داده نمی‌شود ولی در امضای اپ می‌ماند.

⚠️ **این فایل (`karam-release.jks`) و رمزش را گم نکنید** — بدون آن هیچ‌وقت نمی‌توانید همان اپ را به‌روزرسانی کنید. دو نسخه پشتیبان در جای امن (نه گیت!).

### ثبت در GitHub Secrets (نام‌ها دقیقاً همین‌ها):

| Secret | مقدار |
| --- | --- |
| `ANDROID_KEYSTORE_B64` | خروجی دستور زیر (کل فایل base64) |
| `ANDROID_KEYSTORE_PASSWORD` | رمز store |
| `ANDROID_KEY_ALIAS` | `karam` |
| `ANDROID_KEY_PASSWORD` | رمز key |

ساخت base64:

```bash
base64 karam-release.jks > karam-release.b64   # ویندوز: certutil -encode karam-release.jks karam-release.b64
```

مقصدها: GitHub ← مخزن Todoapp ← Settings ← Secrets and variables ← Actions ← New repository secret.

## ۲) بیلد APK در ابر (GitHub Actions)

1. ریپو باید به GitHub پوش شود (در حال حاضر ۲۴+ کامیت جلوتر است و منتظر توکن/پوش دستی شماست).
2. تب **Actions** ← «بیلد اندروید کارام» ← **Run workflow** ← Run.
3. بعد از ~۱۰ دقیقه، در همان اجرا پایین صفحه، آرتیفکت‌ها:
   - `karam-release-apk` ← APK امضاشده (`app-release.apk`) ← **این برای بازار و سایت**
   - `karam-debug-apk` ← فقط برای تست موبایل خودتان
4. اگر Secret امضا ثبت نشده باشد، Release بدون امضا بیلد می‌شود و بازار آن را رد می‌کند — پس اول بخش ۱ را کامل کنید.

---

## ۳) دانلود مستقیم APK از سایت (همین امروز، حتی قبل از بازار)

1. `app-release.apk` را به **`karam-latest.apk`** تغییر نام بدهید.
2. File Manager هاست ← `public_html` ← آپلود.
3. تست: `https://app.hojre24shop.ir/karam-latest.apk` باید دانلود شود.
4. اعلام نسخه جدید داخل اپ: پنل ← تنظیمات ← «به‌روزرسانی اپ» ←
   - `app_latest_version` = `1.0.0`
   - `app_update_url` = `https://app.hojre24shop.ir/karam-latest.apk`
   - (`app_update_notes` اختیاری — متن کوتاه تغییرات)
   ← از این بعد کاربران نسخه‌های قدیمی، کارت «نسخه‌ی جدید منتشر شده» را در تنظیمات می‌بینند.
5. هر انتشار بعدی: `versionCode` را +۱ کنید، `versionName` را بالا ببرید، همین فایل را جایگزین کنید و `app_latest_version` را در پنل به‌روز کنید.

```
کارام، دستیار هوشمند مدیریت وظایف شماست؛ ساده، سریع و کاملاً آفلاین.

■ چرا کارام؟
• آفلاین کامل — بدون اینترنت هم همه‌چیز کار می‌کند؛ کارها اول روی دستگاه خودتان ذخیره می‌شوند.
• ثبت کار هوشمند — بنویسید «جلسه فردا ساعت ۱۰» یا «۵ روز بعد»؛ کارام تاریخ و ساعت را خودش می‌فهمد.
• تقویم و تاریخ شمسی به‌صورت بومی.
• ورود بدون رمز عبور — کد یک‌بارمصرف مستقیم در تلگرام شما.
• اولویت‌بندی و فوریت کارها + یادآوری.
• سینک ابری دوطرفه — با هر دستگاهی که وارد شوید همه‌چیز همان‌جاست.
• تم روشن و تاریب + اندازه‌ی فونت قابل تنظیم.
• پشتیبان‌گیری خودکار از داده‌های شما.

■ کارام پرو
• بسته‌های شغلی آماده: روتیس تریدر، دانش‌آموز، فریلنسر و…
• تحلیل عمقی بهره‌وری: ساعات اوج تمرکز، بهترین روز هفته، روند نرخ تکمیل.

از محتوای کارهای شما برای تبلیغات یا فروش استفاده نمی‌کنیم؛ داده‌ی شما داده‌ی شماست. درخواست حذف حساب = حذف کامل داده‌های سمت سرور.

■ پرداخت
از داخل اپ با درگاه بانکی امن یا کارت‌به‌کارت با تأیید سریع. پایان دوره به نسخه‌ی رایگان برمی‌گردید و هیچ داده‌ای حذف نمی‌شود.

پشتیبانی: از بخش «قوانین و پشتیبانی» داخل اپ یا صفحه‌ی سایت، با ما در ارتباط باشید.
```

## ۵) فرآیند پنل بازار (site.cafebazaar.ir)

1. ثبت‌نام/ورود به پنل ناشران ← «افزودن اپ جدید».
2. شناسه پکیج: `ir.hojre24shop.app` (دقیقاً همین).
3. آپلود فایل APK امضاشده (بخش ۲).
4. پر کردن لیستینگ با متن‌های بخش ۴ + آپلود آیکن و اسکرین‌شات‌ها.
5. اطلاعات تماس و خط‌مشی حریم خصوصی (لینک لندینگ).
6. ارسال برای بررسی — معمولاً ۱ تا ۳ روز کاری. اگر رد شد، دلیل را می‌گویند و فقط فایل/لیستینگ اصلاح می‌شود؛ تجربه‌ی رایج: نسخه‌ی وب فعال (app.hojre24shop.ir) کمک زیادی به تأیید می‌کند.
