# کارام — بسته‌ی هاست v1.11.3 (نصب سریع وب‌اپ + بنر بروزرسانی خودکار + لوگوی رسمی لندینگ — بدون SQL)

> این بسته **پک استقرار کامل** است و از هر وضعیتی ≥ v1.7 یکجا به v1.11.3 می‌رساند.
> **این نسخه هیچ تغییر دیتابیس ندارد** — فقط وب‌اپ به‌روز می‌شود؛ `api/` و `panel/` نسبت به v1.11.2 بیت‌به‌بیت بدون تغییرند.
>
> تغییرات v1.11.3 (سه درخواست صاحب محصول):
> **۱) «نصب سریع کارام» (PWA):** تنظیمات وب ← کارت نو «نصب سریع کارام». روی اندروید/دسکتاپ (کروم/اج/فایرفاکس) دکمه‌ی «نصب» دیالوگ بومی مرورگر را باز می‌کند و کارام بدون فروشگاه روی صفحه‌ی اصلی می‌نشیند. اگر اپ همین حالا نصب/اجرا باشد: «کارام به‌صورت اپ نصب است ✅». سافاری آیفون/آیپد: راهنمای «هم‌رسانی ← Add to Home Screen». پاپ‌آپ خودکار مرورگر سرکوب شده تا جریان نصب در اختیار اپ باشد (رویداد قبل از نمایش گرفته می‌شود).
> **۲) بنر خودکار بروزرسانی:** سرویس‌ورکر دیگر خودش فعال نمی‌شود؛ نسخه‌ی نو در صف می‌ماند و بالای اپ بنر «نسخه‌ی جدید کارام آماده است — بروزرسانی» می‌آید. کلیک کاربر = فعال‌سازی + یک‌بار بارگذاری مجدد. هیچ ریلود وسط کارِ کاربر بدون اجازه‌ی او رخ نمی‌دهد. از این به بعد هر پک نو = همه‌ی کاربران وب خودشان را به‌روز می‌کنند.
> **۳) لوگوی رسمی در لندینگ:** آیکن سبز موقتِ فاز ۱ (مربع سبز + چک‌مارک سفید) از سربرگ لندینگ حذف شد — همان لوگوی رسمی اپ/پنل (میله‌ها + تیک گرادیانی آبی، منبع واحد `frontend/scripts/generate-icons.mjs`) با قاب سفید + فاوآیکن داده‌URI برای تب مرورگر. فایل لندینگ مستقل است: `karam-landing.zip` را جدا آپلود کنید.
> **تغییری در api، پنل، اندروید، versionCode، APP_VERSION یا BACKUP_VERSION نیست؛ هیچ SQL جدیدی نیست.**
> (همه‌ی امکانات v1.11.0 تا v1.11.2 هم داخل همین پک است.)

## نکته‌های فنی
- جریان به‌روزرسانی: `sw.js` نو (بدون `skipWaiting` خودکار) → سرویس‌ورکر نو state=`installed` با وجود `controller` → `onSwWaiting` → بنر → پیام `SKIP_WAITING` → `controllerchange` → ریلود یک‌باره. `reloadArmed` تضمین می‌کند ریلود فقط با کلیک کاربر رخ دهد.
- نصب PWA: رویداد `beforeinstallprompt` در سطح اپ (App) گرفته و سرکوب می‌شود؛ تصمیم نمایش با تابع خالص `installVariant` (۵ حالت: native/installed/button/ios-hint/none) — تست‌شده در `tests/pwa.test.ts`.
- داخل اپ اندروید (APK) هیچ‌کدام فعال نمی‌شود: `registerServiceWorker` و کارت نصب وب روی native غیرفعال‌اند.
- هیچ عدد قیمت، versionCode، APP_VERSION یا BACKUP_VERSION تغییر نکرده است.
- تست‌ها: ۳۱۵ تست فرانت سبز (شامل ۸ تست نو PWA) + ۲۲۵ بررسی e2e در ۸ سوئیت + تایپ‌چک تمیز + بیلد وب نو.
