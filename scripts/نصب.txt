پک کارام v1.7.0 — فاز ۳: قفل واقعی با اثر انگشت + رفع شکاف درگاه پرداخت APK
════════════════════════════════════════════════════════════════════════════

این پک، نسخه‌ی نهایی و تجمیعی است — همه‌ی قابلیت‌های پک‌های قبلی (تا v22)
داخلش هست. اگر آخرین نصب شما karam-host-update-v1.3.0 بوده، همین پک کافی است
ولی «گام SQL» برای شما اجباری است (پایین را دقیق بخوانید).

──────────────────────────────────────────────
الف) مهاجرت دیتابیس — برای ارتقا از v1.3.0 اجباری ⚠️
──────────────────────────────────────────────
از پک 1.4.0 به بعد، واحد پول سرور از ریال به «تومان صحیح» تبدیل شده است.
اگر SQL زیر را اجرا نکنید، بعد از آپلود api/ جدید مسیرهای پرداخت خطای
«ستون ناشناخته» می‌دهند و قیمت‌ها اشتباه نمایش داده می‌شوند.

قبل از اجرا: یک فول‌بک کامل از دیتابیس بگیرید (phpMyAdmin ← Export).
اجرا (تکرارپذیر — چند بار اجرا بی‌ضرر):
  phpMyAdmin ← دیتابیس کارام ← SQL ← محتوای deploy/upgrade-v1.8.sql ← Go

این اسکریپت خودش جدول‌های پشتیبان (_bak_v18_*) می‌سازد و مسیر بازگشت
مستند دارد (docs/INSTALL.md بخش ۱۸-۸).

نکته: ستون‌های کارها (starred/repeat_meta/reminder_minutes و ...) لازم نیست
دستی اجرا شود — کد سرور در اولین سینک خودش اضافه می‌کند (TaskSchema).

──────────────────────────────────────────────
ب) نصب فایل‌ها (سه پوشه — مثل همیشه)
──────────────────────────────────────────────
۱) فایل zip را باز کنید؛ سه بخش می‌بینید: (اپ) · panel · api · deploy

۲) محتوای پوشه‌ی اصلی (اپ) → public_html
   (فایل .htaccess مخفی هم باید آپلود شود)

۳) محتوای panel → public_html/panel

۴) محتوای api → public_html/api
   (پوشه‌های storage را جایگزین نکنید؛ فقط src و cron و index.php و .htaccess)

۵) کش پنل مرورگر: یک بار Ctrl+F5

ترتیب امن: اول SQL (بخش الف) بعد آپلود api/ — اگر برعکس شود فقط تا اجرای
SQL چند دقیقه خطای پرداخت دارید (سینک کارها بی‌تأثیر است).

──────────────────────────────────────────────
ج) APK جدید 1.0.7 (کد ۸) — قفل با اثر انگشت
──────────────────────────────────────────────
دو APK از بیلد ابری (Actions):
  • karam-latest.apk  → حالت پیش‌فرض (پرداخت روشن) — سایت و به‌روزرسانی
  • karam-bazaar.apk  → نسخه‌ی بازار (بدون پرداخت)

قابلیت جدید APK: «قفل با اثر انگشت» واقعی شد —
  • تنظیمات ← قفل با اثر انگشت ← روشن (فعال‌سازی با یک تأیید زنده‌ی اثر انگشت)
  • با هر خروج از برنامه، بازگشت نیازمند اثر انگشت/چهره یا رمز دستگاه است
  • اگر بیومتریک در دسترس نباشد، قفل اعمال نمی‌شود (هیچ‌کس حبس نمی‌شود) و
    علتش در همان ردیف تنظیمات نوشته می‌شود
  • رفع مهم: در APKهای قبلی درگاه پرداخت زیبال باز نمی‌شد (پلاگین بومی مرورگر
    در باندل اندروید نبود) — در 1.0.7 رفع شد؛ بعد از نصب، درگاه واقعاً باز می‌شود

پس از آپلود karam-latest.apk در public_html:
  پنل ← تنظیمات ← app_latest_version = 1.0.7

──────────────────────────────────────────────
د) تست‌های پیشنهادی (۵ مورد)
──────────────────────────────────────────────
۱) بعد از اجرای SQL و آپلود api: در اپ/وب قیمت‌ها درست (تومان) و خرید
   آزمایشی بدون خطا باشد
۲) APK 1.0.7 ← تنظیمات ← قفل با اثر انگشت را روشن کنید (تأیید زنده می‌خواهد)
۳) از برنامه خارج شوید (Home) و برگردید → صفحه‌ی «کارام قفل است» با اثر انگشت باز شود
۴) کلید قفل را خاموش کنید → خروج/بازگشت بدون قفل
۵) در وب (همان حساب) ردیف قفل باید «فقط در نسخه‌ی اندروید» و غیرفعال باشد

قابلیت‌های قبلی — راهنمای کامل در docs/INSTALL.md (بخش ۱۱ و ۱۶ و ۱۷ و ۱۸).
