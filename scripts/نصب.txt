کارام — پک v20 (گام ۲۰ رشد: رفرال + کد هدیه + یادآور تلگرامی — نسخه اپ: ۳.۹.۰)
==============================================================================

این پک شامل هر سه بخش است:
  1) ریشه (index.html، assets و...) — اپ کاربر PWA (نسخه جدید: ۳.۹.۰)
  2) پوشه panel/ — پنل مدیریت (جدید: تب «کدهای هدیه» + ۳ گروه تنظیمات + تخفیف در واریزی‌ها)
  3) پوشه api/ — بک‌اند کامل PHP + cron/ (کرون تلگرام + بکاپ + یادآور جدید)

روش نصب (مثل همیشه):
  1) در داشبورد هاست، فایل zip را در public_html آپلود کنید
  2) روی فایل zip راست‌کلیک → Extract (همان‌جا در public_html)
  3) اپ و پنل را یک بار کامل ببندید و دوباره باز کنید
  4) نسخه‌ی اپ باید «۳.۹.۰» شود (تنظیمات اپ ← پایین صفحه)

جدیدِ این پک — گام ۲۰ (رشد):

  A) دعوت دوستان (رفرال) — «لینک دعوت دوست = روز پرو برای هر طرف»:
     ۱) پنل ← تنظیمات ← گروه «دعوت دوستان — رفرال (v20)» ← روشن + تعداد روز (پیش‌فرض ۷)
     ۲) اپ ← حساب کاربری ← کارت «دعوت دوستان»: کد یکتا + کپی + اشتراک تلگرام
     ۳) دوستتان کد را همان‌جا وارد کند → هر دو طرف N روز پرو می‌گیرید
     قاعده: هر حساب فقط یک‌بار می‌تواند کد کسی را فعال کند

  B) کد هدیه (تخفیف):
     ۱) پنل ← تب جدید «کدهای هدیه» ← «کد جدید» (درصد یا مبلغ ثابت، سقف استفاده، انقضا)
     ۲) اپ ← صفحه پرو ← پرداخت ← شیت روش پرداخت ← «کد هدیه دارید؟» ← بررسی کد
     ۳) تخفیف زنده دیده می‌شود و روی هر دو روش (درگاه و کارت‌به‌کارت) اعمال می‌شود
     قاعده: هر کاربر هر کد فقط یک‌بار؛ شمارش استفاده فقط بعد از تأیید قطعی

  C) یادآور تلگرامی — یک کرون روزانه:
     ۱) پنل ← تنظیمات ← گروه «یادآور تلگرامی (v20)» ← روشن
     ۲) DirectAdmin ← Cron Jobs ← Add New Cron Job — زمان: هر روز 08:00 (دقیقه=0، ساعت=8)
     ۳) دستور: /usr/local/bin/php /home/USERNAME/domains/app.hojre24shop.ir/public_html/api/cron/reminder-cron.php
        (مسیر php و USERNAME را مثل کرون بکاپ/تلگرام دربیاورید)
     وضعیت/دستور کرون آماده: https://app.hojre24shop.ir/api/cron/reminder-cron.php?check=karam-reminder-check
     نکته: پیام فقط به کاربرانی می‌رسد که با تلگرام وارد شده‌اند و کار عقب‌افتاده دارند

  D) چرخه بازخورد: سند docs/FEEDBACK.md (سه سؤال + مسیر جمع‌آوری) — نصب نمی‌خواهد

مهاجرت دیتابیس: خودکار و تکرارپذیر — بار اولی که هر قابلیت استفاده شود،
ستون‌ها/جدول‌ها بی‌صدا ساخته می‌شوند (الگوی همیشگی کارام). نیازی به phpMyAdmin نیست.
(اختیاری: deploy/upgrade-v1.2.sql)

تست‌های پیشنهادی:
  ۱) پنل ← تب «کدهای هدیه» دیده شود → یک کد ۲۰٪ بسازید → در فهرست با بج «فعال» بیاید
  ۲) اپ (نسخه ۳.۹.۰) ← صفحه پرو ← پرداخت ← کد را وارد و «بررسی کد» بزنید → تخفیف زنده دیده شود
  ۳) پنل ← واریزی‌ها → واریزِ با کد هدیه: قیمت خط‌خورده + مبلغ نهایی + بج کد دیده شود
  ۴) پنل ← تنظیمات ← «دعوت دوستان» را روشن کنید → اپ ← حساب کاربری ← کارت دعوت با کد یکتا دیده شود
  ۵) با دو حساب جدا: کد حساب اول را در حساب دوم فعال کنید → هر دو «N روز پرو» بگیرند
     (تلاش دوم با همان حساب اول → خطای «قبلاً فعال کرده‌اید»)
  ۶) صفحه وضعیت یادآور باز شود + کرون نصب شود → فردا صبح پیام «شما N کار عقب‌افتاده دارید»
     در تلگرام کاربرِ دارای کار عقب‌افتاده برسد
