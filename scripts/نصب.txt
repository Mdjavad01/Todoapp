پک کارام v1.11.0 — خلوت‌سازی UX چهاربسته‌ای A/B/C/D (بدون SQL)
════════════════════════════════════════════════════════════════════════

این پک، ارتقای تجمعی از هر وضعیتی ≥ v1.7 به v1.11.0 است.
⚠️ این نسخه هیچ مهاجرت SQL ندارد — فقط فایل‌های اپ به‌روز می‌شوند. اگر هاست شما
هنوز روی v1.10.1 یا قدیمی‌تر است، همین پک + یک‌بار اجرای SQL تجمعی (توضیح بخش الف)
شما را کامل می‌کند؛ اگر روی v1.10.2 هستید، فقط آپلود فایل‌ها.

چی در v1.11.0 نو است (چهار بسته‌ی تأییدشده‌ی صاحب محصول — «یه مدل تمیز کن…»):
  ۱) بسته A — نوار واحد افزودن در همه‌ی صفحه‌ها + خانه/امروز/آمارِ بی‌حاشیه
  ۲) بسته B — جزئیات کار دوسطحی (پشت «بیشتر») + کارت تریدر با «⋯» و «؟»
     + نوع آیتم فقط در لیست‌های تریدر + ردیف «فوری» جدا
  ۳) بسته C — صفحه‌ی واحد «قالب‌ها» با دو بخش رایگان/پرو (رایگان: سوپرمارکت/
     کنکور/سفر/خانه‌تکانی — پرو: تریدر + ۳ بسته‌ی شغلی). تنها مسیر ورود:
     «لیست جدید ← یا از قالب آماده» در خانه. دو ردیف تنظیمات حذف شدند؛
     کارت ارتقا به پرو به همین صفحه می‌رود. قفل تریدر TRADER_REQUIRES_PRO
     (بیلد بازار = برای همه رایگان؛ کاربران فعالِ قبلی دسترسی کامل)
  ۴) اصلاحات — قرارداد «تومب‌استون + ساخت دوباره‌ی لیست پیش‌فرض» + شمارنده‌ی
     «بیشتر • N» روی جزئیات کار
  ۵) بسته D — بنر «کارهای نمونه‌ی قدیمی پیدا شد» حذف شد؛ پاک‌سازی بی‌صدا در
     بوت‌استرپ (فقط حذف نرم) + توست واگرد ۱۰ ثانیه (قرارداد: حداقل ۸ ثانیه)؛
     منطق اسکن دست‌نخورده؛ کار واقعی کاربر هرگز نامزد نمی‌شود
  ۶) هیچ تغییری در api / پنل / اندروید / versionCode / APP_VERSION /
     BACKUP_VERSION نیست
