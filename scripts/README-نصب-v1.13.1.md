## ۱) گام ۰ — بیمه (اجباری، ۳ دقیقه)

## ۲) نصب فایل‌ها (۲ دقیقه)

۱. دانلود `karam-host-update-v1.13.1.zip` (از پیش‌نمایش نشست یا Release).
۲. استخراج **همه‌ی فایل‌ها و پوشه‌ها** روی `public_html` (File Manager ← Extract؛ گزینه‌ی
   جایگزینی را تأیید کنید؛ Show Hidden Files روشن باشد). فایل‌های قدیمی وب و پنل جایگزین می‌شوند؛
   `storage/` و `.env` دست نمی‌خورند.
۳. پوشه‌ی `deploy-sql/` **آپلود/اجرا نشود** — فقط مرجع است.

## ۵) گوشی (APK)

APK باینری مستقل است و محتوای وبِ داخلش از خود باندل سرو می‌شود (از هاست نمی‌آید). بیلد نوِ
APKها (همان `1.0.10 / vc11` — خروجی Actions همین کامیت) وب **۴٫۶٫۲** را داخل خود دارند:
`karam-latest.apk` برای نصب مستقیم و `karam-bazaar.apk` فقط برای فرم کافه‌بازار. نصب روی نسخه‌ی
فعلی بدون از دست رفتن داده می‌نشیند. `app_latest_version` پنل را عوض نکنید.
