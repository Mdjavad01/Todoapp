# کارام — بسته‌ی هاست v1.11.1 (خلوت‌سازی UX چهاربسته‌ای A/B/C/D + دو اصلاح بسته‌ی D — بدون SQL)

> این بسته **پک استقرار کامل** است (همان محتوای v1.11.0 + دو اصلاح صاحب محصول روی بسته‌ی D) و از هر وضعیتی ≥ v1.7 یکجا به v1.11.1 می‌رساند.
> **این نسخه هیچ تغییر دیتابیس ندارد** — فقط فایل‌های وب‌اپ به‌روز می‌شوند (api و پنل هم بازآپلود بی‌ضرر است، هیچ‌چیزشان تغییر نکرده).
>
> تغییرات v1.11.1 (دو اصلاح صاحب محصول — «قبل از ادغام، دو اصلاح کوچک روی بسته D»):
> **اصلاح ۱ — لیست خالیِ کاربر هرگز نامزد پاک‌سازی نمی‌شود:** لیست خالیِ تازه‌ساخته‌شده‌ی کاربر (هر چقدر هم هم‌نام لیست‌های سید — مثلاً «کاری») هرگز پاک نمی‌شود. لیست خالیِ نام‌سید فقط وقتی نامزد است که «از دوره‌ی سید» باشد: createdAt لیست در همان پنجره‌ی زمانیِ کارهای دموی همان دستگاه باشد (حداقل ۳ کار دموی هم‌دوره در ۵ ثانیه)، یا در همان اسکن کار دموی خودِ همان لیست نامزد شده باشد. بدون هیچ کار دمو روی دستگاه، هیچ لیستی نامزد نمی‌شود.
> **اصلاح ۲ — اسکن فقط تا اولین تصمیم قطعی:** اسکن پاک‌سازی در هر بوت تکرار نمی‌شود؛ بعد از اولین تصمیم قطعی (پاک‌سازی انجام شد، یا اسکنِ بعد از اتمام موفق اولین سینک چیزی نیافت) pref ثبت و اسکن برای همیشه متوقف می‌شود — حتی بعد از واگرد. حساب ابری فقط بعد از اولین سینکِ موفق «چیزی نیافت» قطعی می‌گیرد؛ مهمان همان بوت اول تصمیم می‌گیرد؛ اگر مهمان بعداً وارد حساب شود، تصمیم قبلی باطل و اسکن دوباره فعال می‌شود.
> (همه‌ی امکانات v1.11.0 هم داخل همین پک است: بسته‌های A/B/C/D — نوار واحد افزودن، جزئیات کار دوسطحی، صفحه‌ی واحد «قالب‌ها» با رایگان/پرو، پاک‌سازی بی‌صدای داده‌ی نمونه با توست واگرد ۱۰ ثانیه.)
> **تغییری در api و پنل و اندروید نیست؛ در versionCode / APP_VERSION / BACKUP_VERSION هم نیست.**

## گام ۲ — آپلود فایل‌ها
1. محتوای **ریشه‌ی** بسته → `public_html` (فایل مخفی `.htaccess` هم — جایگزین کن)

## گام ۳ — تست دودی

2. اپ وب با Ctrl+F5 ← **خانه**: بنر تریدر و ردیف دائمی «قالب‌های آماده» از خانه حذف شده‌اند — فقط ردیف «لیست جدید / یا از قالب آماده» هست.

## نکته‌ها
- «پاک‌سازی بی‌صدا» فقط تا **اولین تصمیم قطعی** اجرا می‌شود (pref `demo-cleanup-v1`): نامزد پیدا شد ⇒ پاک‌سازی + توقف؛ چیزی نیافت ⇒ بعد از اولین سینکِ موفق (یا برای مهمان همان بوت اول) توقف. بعدش دیگر هرگز اسکن نمی‌شود — حتی بعد از «واگرد». اگر مهمان بعداً وارد حساب ابری شود، تصمیم قبلی باطل و اسکن دوباره فعال است.
- نامزدها با پنج شرط انباشته‌ی محافظه‌کارانه پیدا می‌شوند (عنوان دقیق دمو + لیست نام‌سید + بی‌ستاره + دسته‌ی ≥۳ در ۵ ثانیه + هرگز ویرایش‌نشده) — کار واقعی کاربر با عنوان شبیه دمو در لیست خودش هرگز لمس نمی‌شود.
- **لیست‌های خالی فقط با «دوره‌ی سید» نامزدند** (اصلاح ۱.۱۱.۱): createdAt لیست هم‌پنجره‌ی کارهای دموی همان دستگاه، یا لیستی که با همین پاک‌سازی خالی شده — لیست خالیِ تازه‌ساخت کاربر هرگز.
- بازیابی از فایل پشتیبان داده را «ادغام» می‌کند؛ اگر پشتیبانِ خیلی قدیمی شامل داده‌ی نمونه باشد، اسکنِ خودکار دوباره اجرا نمی‌شود (تصمیم قطعی گرفته شده) — این داده با حذف دستی پاک می‌شود.
- هیچ عدد قیمت، versionCode، APP_VERSION یا BACKUP_VERSION در این نسخه تغییر نکرده است.
- تست‌ها: ۳۰۷ تست فرانت سبز (۱۳ تست نو برای دو اصلاح) + ۲۲۵ بررسی e2e (۸ سوئیت) — تایپ‌چک تمیز.
