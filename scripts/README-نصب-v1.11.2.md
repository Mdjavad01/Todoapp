# کارام — بسته‌ی هاست v1.11.2 (صفحات مستقل حریم خصوصی/قوانین + هاردنینگ IP — بدون SQL)

> این بسته **پک استقرار کامل** است و از هر وضعیتی ≥ v1.7 یکجا به v1.11.2 می‌رساند.
> **این نسخه هیچ تغییر دیتابیس ندارد** — فایل‌های وب‌اپ + یک فایل بک‌اند (Request.php) به‌روز می‌شوند.
>
> تغییرات v1.11.2 (پک امنیتی پیش از ارسال فرم کافه‌بازار — «انجام بده همه رو به ترتیب»):
> **۱) صفحه‌ی مستقل «حریم خصوصی» و «قوانین استفاده»** — `https://دامنه/privacy/` و `https://دامنه/terms/` از این به بعد صفحه‌های واقعی و قابل‌بازدیدند (قبلاً فقط انکر داخل لندینگ و شیت درون‌اپ بود). استاتیک و صفر وابستگی (بدون فونت/اسکریپت بیرونی)، دارک/لایت خودکار، هم‌خانواده‌ی لندینگ. محتوای حریم خصوصی کامل‌تر از شیت درون‌اپ است: جدول «دسته‌ی داده / مثال / کجا / مدت نگهداری»، بکاپ سروری (۷ نسخه، ماسک رازها)، مسیر حذف حساب و export، کانال‌های OTP و ارسال موبایل به درگاه زیبال، رده‌ی سنی +۳، تعهد عدم فروش داده. بازبین کافه‌بازار لینک قابل‌بازدید می‌خواهد — این همان لینک است: **در فرم بازار آدرس `https://app.hojre24shop.ir/privacy/` را بگذارید.**
> **۲) هاردنینگ IP پشت CDN (کلید .env: TRUST_PROXY):** `Request::ip()` که مبنای سقف نرخ OTP است، حالا با تنظیم صریح `TRUST_PROXY=1` در `.env` هاست، IP واقعی کاربر را از هدر پروکسی (CF-Connecting-IP یا X-Forwarded-For از راست) می‌خواند. **پیش‌فرض خاموش = رفتار قبلی بیت‌به‌بیت** — روی نصب مستقیم (بدون Cloudflare/پروکسی) هیچ کاری لازم نیست و هرگز `1` نگذارید (هدرها از سمت کلاینت قابل جعل‌اند). فقط اگر هاست پشت CDN رفت: `TRUST_PROXY="1"` به `.env` اضافه کنید.
> (همه‌ی امکانات v1.11.1 و v1.11.0 هم داخل همین پک است: خلوت‌سازی UX چهاربسته‌ای A/B/C/D + دو اصلاح بسته‌ی D.)
> **تغییری در پنل، اندروید، versionCode، APP_VERSION یا BACKUP_VERSION نیست؛ هیچ SQL جدیدی نیست.**

## نکته‌ها
- صفحات نو **استاتیک**‌اند (هیچ PHP/دیتابیسی نمی‌خواهند) و سرویس‌ورکر اپ مزاحمشان نمی‌شود (ناوبری‌ها شبکه-اول است) — مستقیم و همیشه تازه باز می‌شوند.
- محتوای دو صفحه از همان منابع درون‌اپ (TermsSheet + مستندات بکاپ/حذف حساب) نوشته شده و با آن‌ها سازگار است؛ اگر روزی متن شیت اپ عوض شد، این دو صفحه را هم همان‌جا به‌روز کنید (فایل‌ها: `frontend/public/privacy/index.html` و `frontend/public/terms/index.html`).
- `TRUST_PROXY` پیش‌فرض خاموش است و در `.env.example` مستند شده. سقف ۲۰ OTP/ساعت بر پایه‌ی IP فقط وقتی معنا دارد که IP واقعی باشد — روی نصب مستقیم همین REMOTE_ADDR درست است.
- هیچ عدد قیمت، versionCode، APP_VERSION یا BACKUP_VERSION در این نسخه تغییر نکرده است.
- تست‌ها: ۳۰۷ تست فرانت سبز + ۲۲۵ بررسی e2e (۸ سوئیت) — تایپ‌چک تمیز + بیلد وب نو. (PHP در محیط ساخت در دسترس نبود؛ تغییر بک‌اند فقط `Request::ip()` با گارد پیش‌فرض-خاموش است — بدون تنظیم، مسیر کد عیناً قبلی است.)
