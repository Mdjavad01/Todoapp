# کارام — بسته‌ی هاست v1.10.2 (فیکس UX کشف قالب‌ها + پیش‌فرض شنبه برای ریویو هفتگی)

> این بسته **پک استقرار کامل** است (همان محتوای v1.10.1 + تغییرات v1.10.2) و از هر وضعیتی ≥ v1.7 یکجا به v1.10.2 می‌رساند.
> **این نسخه هیچ تغییر دیتابیس ندارد** — فقط فایل‌های وب‌اپ به‌روز می‌شوند (api هم بازآپلود بی‌ضرر است، هیچ چیزش تغییر نکرده).
>
> تغییرات v1.10.2 (درخواست صاحب محصول — «کشف قالب‌ها سخت است»):
> ۱. بنر «چک‌لیست معامله‌گری آماده است» در **خانه** — فقط تا وقتی تمپلیت تریدر فعال نشده + قابل‌بستن با ✗
> ۲. ردیف دائمی «قالب‌های آماده» در خانه — کنار «لیست جدید» (یک‌لمسی به‌جای پنهان‌بودن در تنظیمات)
> ۳. پیش‌فرض روز «ریویو هفتگی» از جمعه → **شنبه** (برای فعال‌سازی‌های جدید؛ روزش از جزئیات آیتم قابل تغییر است)
> ۴. محتوای ۵ لیست تریدر همان است: قوانین من (پین‌شده) / پیش از بازار (روزانه) / قبل از معامله (+ فوتر «اگر حتی یکی نه بود → معامله نکن») / بعد از بازار (روزانه) / ریویو هفتگی — با فیلدهای عدد/یادداشت/انتخاب/امتیاز
> **تغییری در api و پنل نیست؛ در versionCode / APP_VERSION / BACKUP_VERSION هم نیست.**

## گام ۲ — آپلود فایل‌ها
1. محتوای **ریشه‌ی** بسته → `public_html` (فایل مخفی `.htaccess` هم — جایگزین کن)
2. `panel/` و `api/` بدون تغییر هستند؛ آپلودشان اختیاری است (بی‌ضرر).
   اگر آپلود کردی: پوشه‌های `storage/cache|logs|backups` و فایل `.env` هاست را **جایگزین نکن**.
3. یک بار Ctrl+F5 در اپ وب (سرویس‌ورکر باندل نو را با sw.js نو precache می‌کند).
**بازگشت:** zip وضعیت ابتدای گام را سر جایش استخراج کنید.

## گام ۳ — تست دودی
1. `https://app.hojre24shop.ir/api/health` → `"status":"ok"`
2. اپ وب با Ctrl+F5 ← **خانه** ← اگر تریدر فعال نباشد بنر «چک‌لیست معامله‌گری آماده است» بالا آمده + ردیف «قالب‌های آماده» کنار «لیست جدید» دیده می‌شود.
3. «قالب‌های آماده» ← کارت تریدر ← دکمه‌ها کار می‌کنند.
**بازگشت:** فایل‌های گام ۲ را برگردانید.

## گام ۴ — محتوای نو تمپلیت برای کسی که قبلاً فعال کرده
برای گرفتن پیش‌فرض شنبه در «ریویو هفتگی»: «تنظیمات ← قالب‌های آماده ← کارت تریدر ← **بازنشانی به حالت پیش‌فرض**» و سپس دوباره «فعال‌سازی تمپلیت ترید» (داده‌ی فعلی ۵ لیست تومب‌استون و نسخه‌ی نو ساخته می‌شود؛ تاریخچه‌ی کارها در «انجام‌شده‌ها» می‌ماند).
**بازگشت:** ندارد (اختیاری — جمعه هم درست است و کار می‌کند).
