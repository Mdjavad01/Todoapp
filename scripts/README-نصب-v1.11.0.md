# کارام — بسته‌ی هاست v1.11.0 (خلوت‌سازی UX چهاربسته‌ای A/B/C/D — بدون SQL)

> این بسته **پک استقرار کامل** است (همان محتوای v1.10.2 + تغییرات v1.11.0) و از هر وضعیتی ≥ v1.7 یکجا به v1.11.0 می‌رساند.
> **این نسخه هیچ تغییر دیتابیس ندارد** — فقط فایل‌های وب‌اپ به‌روز می‌شوند (api و پنل هم بازآپلود بی‌ضرر است، هیچ‌چیزشان تغییر نکرده).
>
> تغییرات v1.11.0 (چهار بسته‌ی تأییدشده‌ی صاحب محصول روی شاخه‌ی feat/ui-declutter):
> **بسته A** — نوار واحد افزودن در همه‌ی صفحه‌ها + خانه/امروز/آمارِ بی‌حاشیه (خلوت‌سازی)
> **بسته B** — جزئیات کار دوسطحی (فیلدهای کم‌استفاده پشت «بیشتر») + کارت تریدر با منوی «⋯» و راهنمای «؟» + نوع آیتم فقط در لیست‌های تریدر + ردیف «فوری» جدا
> **بسته C** — صفحه‌ی واحد «قالب‌ها» با دو بخش رایگان/پرو: رایگان = سوپرمارکت/کنکور/سفر/خانه‌تکانی، پرو = تریدر + ۳ بسته‌ی شغلی؛ تنها مسیر ورود: **«لیست جدید ← یا از قالب آماده»** در خانه؛ ردیف‌های قالب‌ها از تنظیمات حذف شدند؛ کارت ارتقا به پرو در تنظیمات و آمار به همین صفحه می‌رود؛ قفل تریدر با ثابت واحد `TRADER_REQUIRES_PRO` (بیلد بازار/پرداخت خاموش = برای همه رایگان؛ بیلد با پرداخت = قفل برای غیرپرو؛ کاربران فعالِ قبلی همیشه دسترسی کامل)
> **اصلاحات صاحب محصول** — قرارداد «تومب‌استون + ساخت دوباره‌ی لیست پیش‌فرض» با تست واحد تثبیت شد + شمارنده‌ی «بیشتر • N» روی جزئیات کار (فیلد پنهانِ دارای مقدار ⇒ عدد روی دکمه)
> **بسته D** — بنر «کارهای نمونه‌ی قدیمی پیدا شد. پاک شوند؟» حذف شد؛ پاک‌سازی **بی‌صدا** در بوت‌استرپ با «فقط حذف نرم» + توست واگرد که **۱۰ ثانیه** می‌ماند (قرارداد حداقل ۸ ثانیه)؛ منطق اسکن بیت‌به‌بیت دست‌نخورده؛ واگرد روی سینک هم برنده‌ی LWW است
> **تغییری در api و پنل و اندروید نیست؛ در versionCode / APP_VERSION / BACKUP_VERSION هم نیست.**

## گام ۱ — SQL؟ نه!
هیچ مهاجرتی لازم نیست. اگر خواستی احتیاط کامل، یک Export از phpMyAdmin بگیر (خوب است همیشه) ولی الزام نیست.
**بازگشت:** ندارد.

## گام ۲ — آپلود فایل‌ها
1. محتوای **ریشه‌ی** بسته → `public_html` (فایل مخفی `.htaccess` هم — جایگزین کن)
2. `panel/` و `api/` بدون تغییر هستند؛ آپلودشان اختیاری است (بی‌ضرر).
   اگر آپلود کردی: پوشه‌های `storage/cache|logs|backups` و فایل `.env` هاست را **جایگزین نکن**.
3. یک بار Ctrl+F5 در اپ وب (سرویس‌ورکر باندل نو را با sw.js نو precache می‌کند).
**بازگشت:** zip وضعیت ابتدای گام را سر جایش استخراج کنید.

## گام ۳ — تست دودی
1. `https://app.hojre24shop.ir/api/health` → `"status":"ok"`
2. اپ وب با Ctrl+F5 ← **خانه**: بنر تریدر و ردیف دائمی «قالب‌های آماده» از خانه حذف شده‌اند — فقط ردیف «لیست جدید / یا از قالب آماده» هست.
3. «لیست جدید ← یا از قالب آماده» ← صفحه‌ی واحد «قالب‌ها» با دو بخش «رایگان» و «پرو».
4. جزئیات یک کار با یادآور/اولویت ⇒ روی دکمه‌ی «بیشتر» شمارنده‌ی «بیشتر • ۱» و بالاتر.
**بازگشت:** فایل‌های گام ۲ را برگردانید.

## گام ۴ — نکته برای کسی که قبلاً تریدر فعال کرده
دسترسی تریدرِ کاربر فعال **دست‌نخورده** می‌ماند (پرچم فعال‌سازی قبلی محفوظ است). برای گرفتن روز شنبه در «ریویو هفتگی» (اگر هنوز نگرفته‌ای): «لیست جدید ← یا از قالب آماده ← کارت تریدر ← **بازنشانی به حالت پیش‌فرض**» و سپس دوباره «فعال‌سازی تمپلیت ترید» (داده‌ی فعلی ۵ لیست تومب‌استون و نسخه‌ی نو ساخته می‌شود؛ تاریخچه‌ی کارها در «انجام‌شده‌ها» می‌ماند).
**بازگشت:** ندارد (اختیاری — جمعه هم درست است و کار می‌کند).

## گام ۵ — انتشار APK (آخرِ آخر)
تغییری در اندروید نیست — بیلد 1.0.9 (versionCode ۱۰) طبق برنامه از main ساخته می‌شود و همین قابلیت‌ها را دارد.

## نکته‌ها
- «پاک‌سازی بی‌صدا» فقط یک‌بار در هر نصب اجرا می‌شود (pref `demo-cleanup-v1`)؛ نامزدها با پنج شرط انباشته‌ی محافظه‌کارانه پیدا می‌شوند (عنوان دقیق دمو + لیست نام‌سید + بی‌ستاره + دسته‌ی ≥۳ در ۵ ثانیه + هرگز ویرایش‌نشده) — کار واقعی کاربر با عنوان شبیه دمو در لیست خودش هرگز لمس نمی‌شود.
- هیچ عدد قیمت، versionCode، APP_VERSION یا BACKUP_VERSION در این نسخه تغییر نکرده است.
- تست‌ها: ۲۹۴ تست فرانت سبز + ۲۲۵ بررسی e2e (۸ سوئیت) — تایپ‌چک تمیز.
